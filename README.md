¡¡ FANSITE DE OLIVIA RODRIGO !!

Fansite de la cantante Olivia Rodrigo desarrollado en HTML y migrado a REACT.JS, dentro se puede encontrar información de su carrera musical, su carrera actoral y giras, aparte de un cuestionario con inputs y control de las respuestas desde la consola.

 **React.js** (Vite)
 **JavaScript (ES6+)** / JSX
 **CSS3** (Estilos globales y modulares)
 **HTML5** (Semántico)
 
--FUNCIONALIDADES
**Diseño modular e interactivo:** Construido mediante componentes reutilizables en React.
* **Mapeo dinámico de datos:** Uso intensivo de arreglos de objetos y método `.map()` para listas (Filmografía, Cuestionario, etc.).
* **Manejo de estado dinámico (`useState`):** Formulario controlado que captura, valida, muestra en consola y resetea las respuestas del usuario.
* **Assets locales procesados:** Importación directa de imágenes en los componentes para asegurar un build optimizado por Vite.
